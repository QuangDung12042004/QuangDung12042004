### 🧠 Engineering Philosophy & Focus

- 🏗️ **Architectural Design:** Specializing in **Clean Architecture**, **Domain-Driven Design (DDD)**, and **CQRS** patterns to ensure modularity and maintainability.
- ⚡ **High Concurrency & Data Integrity:** Solving race conditions and data conflicts using **Optimistic Concurrency (`RowVersion`)** and hybrid data layers (**EF Core + Dapper**).
- 🌐 **Distributed Systems:** Designing resilient microservices workflows with **YARP API Gateway**, **RabbitMQ** event-driven messaging, and rate-limiting policies.
- 🌱 **Continuous Evolution:** Actively expanding into **Cloud-Native ecosystems (Kubernetes)**, **Distributed Caching (Redis)**, and advanced system performance tuning.

### 🚀 Featured Engineering Projects

#### 🏨 [HotelSystems — Enterprise Hotel Management & POS System](https://github.com/QuangDung12042004/HotelSystems)
> *Microservices-based platform designed for hotel chains, integrating booking pipelines and point-of-sale operations.*

- **Routing & Security:** Centralized reverse-proxy using **YARP API Gateway** with token authorization and traffic rate limiting.
- **Data Concurrency:** Handled room-reservation race conditions with **Optimistic Concurrency Control (`RowVersion`)** to prevent double-booking.
- **Performance Strategy:** Implemented a hybrid ORM approach — **EF Core** for transactional updates and **Dapper** for high-speed read queries.
- **Tech Stack:** `.NET 8`, `C#`, `YARP`, `EF Core`, `Dapper`, `MSSQL`, `React`, `Docker`

#### 🛒 [NexusCommerce — Modular E-Commerce Architecture](https://github.com/QuangDung12042004/NexusCommerce)
> *Scalable, enterprise-ready e-commerce core engineered around maintainability and decoupled domain services.*

- **Layered Isolation:** Built strictly following **Clean Architecture** to decouple business logic from framework dependencies.
- **Command Query Separation:** Utilized **CQRS** principles to optimize write throughput and facilitate independent query scaling.
- **Extensible Boundaries:** Formulated service modules around Bounded Contexts, ready to migrate into standalone microservices.
- **Tech Stack:** `C#`, `.NET 8`, `Clean Architecture`, `CQRS`, `MSSQL`, `EF Core`
